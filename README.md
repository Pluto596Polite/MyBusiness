# MyBusiness

Marketing site for my web-design business — hand-coded static HTML, no build step.

- `index.html` — the entire site (styles inline, fonts from Google Fonts)
- Hosted on GitHub Pages

## Editing

Open `index.html`, change the text, commit, push. GitHub Pages redeploys in about a minute.

Placeholders still to replace: business name, form endpoint (`YOUR_FORM_ID`), the three portfolio slots.
